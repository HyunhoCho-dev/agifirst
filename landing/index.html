📝 사용 방법

  1. Groq API 키를 입력하세요
  2. 운영체제를 선택하세요
  3. 다운로드 버튼을 클릭하세요
  4. Windows: ZIP 파일을 압축 해제한 후 AGIfirst.exe를 실행하세요
  5. 브라우저가 자동으로 열립니다!

🛡️ 보안 경고 안내 (Windows)

ZIP 파일 다운로드: ZIP 파일은 대부분 문제없이 다운로드됩니다.

만약 브라우저 경고가 나타나면:

  • Chrome: 다운로드 바에서 "^" 클릭 → "보관" 또는 "유지" 선택
  • Edge: "계속 유지" 버튼 클릭
  • Firefox: 다운로드 목록에서 파일을 찾아 실행

Windows Defender 경고 (압축 해제 후 실행 시):

⚠️ "Windows의 PC 보호"

  • "추가 정보" 클릭
  • "실행" 버튼 클릭
